# JEDAI · Guardiões dos Dados

Mini-game educativo de plataforma (16-bit) sobre como usar IA no trabalho sem colocar a privacidade em risco.
Em 3 planetas, você derrota os maus hábitos e libera as 3 regras de ouro:

1. Proteja os dados antes de enviar.
2. Confira a ferramenta e o uso permitido.
3. Revise antes de compartilhar.

**Jogar:** https://julietadienstmann-web.github.io/jedai-guardioes-dos-dados/

- Funciona no navegador do computador e do celular, sozinho ou em dupla online (cada um no seu computador).
